# Small synthetic recording

`synthetic_events.csv` is a 320-event, 32×24 moving-edge fixture. Its timestamps are integer microseconds and its polarity is signed `-1/+1`. It has no camera poses and is not suitable for evaluating visual odometry.

```bash
python scripts/generate_example.py
adaptive-event-vo view examples/synthetic_events.csv \
  --width 32 --height 24 --timestamp-unit us \
  --output outputs/example.png
```

The fixture is generated by this project under its MIT license. See [the data contract](../docs/datasets.md) for sampling and timestamp details.
